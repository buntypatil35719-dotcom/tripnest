## 📖 About The Project

The **Travel Booking System** is a full-stack web application that allows users to explore destinations, view travel packages, and book trips.

It is developed using **React for frontend**, **Node.js & Express for backend**, and **MySQL as the database**.

---

## ✨ Features

✔️ User Registration & Login
✔️ Browse Travel Packages
✔️ View Package Details
✔️ Book Trips Online
✔️ Admin Panel for Managing Packages
✔️ REST API Integration
✔️ Responsive UI

---

## ⚙️ Installation & Setup

### 1️⃣ Clone Repository

```bash
git clone https://github.com/kishanisaubhagya897-lang/travel-booking-system.git
cd travel-booking-system
```

---

## 🔹 Backend Setup (Node.js)

```bash
cd backend
npm install
```

Create `.env` file:

```env
DB_HOST=localhost
DB_USER=root
DB_PASSWORD=
DB_NAME=tbs
PORT=5000
```

Run backend:

```bash
npm start
```

---

## 🔹 Frontend Setup (React)

```bash
cd frontend
npm install
npm start
```

---

## 🗄️ Database Setup

To set up the database:

* Open phpMyAdmin
* Create a new database:
   tbs
* Import the SQL file:
   * Click **Import**
   * Choose file: `tbs.sql`
   * Click **Go**


📁 Database file included in this repository:
[Download Database](tbs.sql)
